# Dr.Marine UUV

Affordable USV + UUV drone system for monitoring reefs and seaweed farms in Zanzibar.
This repo contains an interactive demonstration (SIMULATION) plus supporting documentation.

## Files
- `dr-marine-uvv.html` — single-file interactive demo (Three.js vendored inline, runs offline).
- `dr-marine-uuv_pitch-and-docs.md` — pitch + technical/non-technical documentation + ethics.
- `dr-marine-uvv_factcheck.md` — fact-check of domain claims, with sources.
- `concept-doc_section9_updated.md` — corrected claims register (drop-in for the concept doc).

All data in the demo is generated client-side and labelled SIMULATION. Not a deployed product.
